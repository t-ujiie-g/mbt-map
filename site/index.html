WebGIS in the browser, written in MoonBit

Maps, GIS data, spatial analysis, web services and 3D city models in one lightweight toolkit. Each part loads only when a page first uses it.

Get started Examples Documentation

npm install mbt-map · moon add t-ujiie-g/mbtmap

One toolkit

The map is one entry point; the rest are separate modules with their own WebAssembly, loaded in workers when first called.

Maps

Vector, raster and terrain tiles, GeoJSON, PMTiles, labels, 3D terrain, globe, extrusions, lights and shadows, in the MapLibre style specification.

mbt-map

Data

CSV, WKT/WKB, Shapefile, TopoJSON, KML/KMZ, GPX, FlatGeobuf, GeoTIFF/COG in; GeoJSON, CSV, KML out; coordinate systems.

mbt-map/data

Analysis

Measures, spatial relations, buffers and overlays, Voronoi, interpolation, contours, clustering, routing, classification, viewsheds.

mbt-map/analysis

Web services

WMS, WMTS, WFS, OGC API and ArcGIS REST layers as sources and features.

mbt-map/services

3D

glTF models, 3D Tiles, I3S and LAS point clouds, with picking, lines of sight and clipping.

mbt-map/3d

Tools

Headless UI controllers, search, drawing and editing, geodesic measurement.

mbt-map/ui · /search · /draw · /geodesic

Write it your way

A JavaScript API shaped like MapLibre GL JS's, a web component for any framework, and a typed MoonBit API.

JavaScript

import { Map } from "mbt-map";

const map = new Map({
  container: "map",
  style: "./style.json",
  center: [139.7671, 35.6812],
  zoom: 14,
});

Web component

<script type="module">
  import "mbt-map/element";
</script>
<mbt-map style-url="./style.json"
  center="139.7671,35.6812" zoom="14">
</mbt-map>

MoonBit

let map = @mbtmap.Map::new(
  "map",
  style=@style.Style::url("./style.json"),
  center=@mbtmap.lnglat(139.7671, 35.6812),
  zoom=14.0,
)
map.on(Load, _ => println("loaded")) |> ignore
