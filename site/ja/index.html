MoonBit で書いた、ブラウザの WebGIS

地図、GIS のデータ、空間解析、Web サービス、3D の都市モデルを、1 つの軽いライブラリに。どの部分も、ページが初めて使うときに読み込みます。

はじめる 例を見る README（日本語）

npm install mbt-map · moon add t-ujiie-g/mbtmap

ドラッグ、ズーム、駅をクリック

1 つの道具箱

地図は 1 つの入口で、ほかはそれぞれ自分の WebAssembly を持つ別のモジュールです。初めて呼んだときに Worker で読み込みます。

地図

ベクトル・ラスタ・標高のタイル、GeoJSON、PMTiles、ラベル、3D の地形、地球儀、建物の押し出し、光と影。スタイルは MapLibre のスタイル仕様。

mbt-map

データ

CSV、WKT/WKB、Shapefile、TopoJSON、KML/KMZ、GPX、FlatGeobuf、GeoTIFF/COG を読み、GeoJSON、CSV、KML に書き出す。座標系の変換も。

mbt-map/data

解析

計測、空間関係、バッファとオーバーレイ、ボロノイ、補間、等値線、クラスタリング、経路探索、階級区分、可視域。

mbt-map/analysis

Web サービス

WMS、WMTS、WFS、OGC API、ArcGIS REST のレイヤーを、ソースや地物として。

mbt-map/services

3D

glTF のモデル、3D Tiles、I3S、LAS の点群。地物の選択、見通し、断面も。

mbt-map/3d

道具

見た目を持たない UI のコントローラ、検索、作図と編集、楕円体の上の計測。

mbt-map/ui · /search · /draw · /geodesic

好きな書き方で

MapLibre GL JS と同じ形の JavaScript の API、どのフレームワークでも使える Web Component、型付きの MoonBit の API。

JavaScript

import { Map } from "mbt-map";

const map = new Map({
  container: "map",
  style: "./style.json",
  center: [139.7671, 35.6812],
  zoom: 14,
});

Web Component

<script type="module">
  import "mbt-map/element";
</script>
<mbt-map style-url="./style.json"
  center="139.7671,35.6812" zoom="14">
</mbt-map>

MoonBit

let map = @mbtmap.Map::new(
  "map",
  style=@style.Style::url("./style.json"),
  center=@mbtmap.lnglat(139.7671, 35.6812),
  zoom=14.0,
)
map.on(Load, _ => println("loaded")) |> ignore

例

国土地理院の配信タイルと、PLATEAU の 3D 都市モデルをそのまま読んで動きます。

ショーケース

検索、レイヤー、作図、計測、解析、データ、Web サービスを 1 つのアプリに。

import { Map } from "mbt-map"

ショーケース：Web Component

同じアプリを <mbt-map> 要素で。

<mbt-map>

ショーケース：React

同じアプリを React 19 で。

<mbt-map onmbt-map-load={…}>

PLATEAU の 3D 都市

mbt-map/3d
